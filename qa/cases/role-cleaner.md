# Тест-кейсы: CLEANER (уборщица)

Минимальный контур: проход по QR, свой пропуск, обращения к администрации.
Админских разделов в меню нет. Сквозные проверки (`CONV-*`) применимы.

Приглашение: OWNER/ADMIN → **«Сотрудники»** → вкладка **«Администраторы»**, роль **Уборщица**.
Первый вход по письму с временным паролем — экран смены пароля (см. `TC-OWNER-USERS-02`).

Руководство: `user-guides/ru/role-uborshchitsa.md`.

---

## Меню и доступ

### TC-CLEANER-NAV-01 — [Отображение] Пункты меню
- **Ожидаемый результат:** видны **Главная**, группа **«Моё»** (**Проход (QR)**, **Мои пропуска**, **Обращения**), **Обратная связь**.
- Нет: расписание, залы, финансы, сотрудники/клиенты, настройки, новости, заявки, биллинг, субаренда, экспорт.

### TC-CLEANER-NAV-02 — [Доступ] Прямой URL админских разделов
- **Шаги:** открыть `/go/:slug/manage/finance/turnover`, `/rooms`, `/staff`, `/settings`.
- **Ожидаемый результат:** редирект на **Главную** (guard), не 200 с формой OWNER.

---

## Главная и проход по QR

### TC-CLEANER-DASH-01 — [Отображение] Личная главная
- **Ожидаемый результат:** кнопка **«Отметиться по QR»**, переход в **«Обращения»**, карточка пропуска (если выдан). Не админ-панель KPI.

### TC-CLEANER-SCAN-01 — [Кнопка] Проход по станционному QR
- **Шаги:** **«Проход (QR)»** (`/manage/me/scan`) → сканирование станционного QR.
- **Ожидаемый результат:** `POST /access/gate/scan` (роль CLEANER допускается); успешный проход или отказ по политике шаблона/графика.

### TC-CLEANER-SCAN-02 — [Кнопка] Проход по токену личного пропуска
- **Ожидаемый результат:** при наличии пропуска — отметка по токену; без пропуска — отказ.

### TC-CLEANER-ACCESS-01 — [Отображение] Только свои пропуска
- **Ожидаемый результат:** **«Мои пропуска»** — список текущего пользователя; нет шаблонов, станции QR, журнала, оплаты/возврата.

---

## Обращения сотрудника

### TC-CLEANER-REQ-01 — [Кнопка][Сохранение] Создать обращение
- **Шаги:** **«Обращения»** (`/manage/me/requests`) → отгул / замена / «не смогу прийти» → сохранить.
- **Ожидаемый результат:** строка в таблице со статусом **Новое**; OWNER/ADMIN видит её в **«Обращения сотрудников»**.

### TC-CLEANER-REQ-02 — [Отображение] Статусы
- **Ожидаемый результат:** после обработки администрацией статус (Принято / Согласовано / Отклонено) виден у CLEANER без права менять его.

## Обратная связь и приватность

### TC-CLEANER-FEEDBACK-01 — [Кнопка][Сохранение] Обращение на платформу
- **Ожидаемый результат:** отправка тикета/чата как у других тенант-ролей.

### TC-CLEANER-PRIVACY-01 — [Кнопка] Запрос на удаление аккаунта
- **Ожидаемый результат:** удаление доступно (не OWNER / не SUPER_*); см. `TC-ANON-PRIVACY-04`.
