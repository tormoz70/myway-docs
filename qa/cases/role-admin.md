# Тест-кейсы: ADMIN (администратор студии)

`ADMIN` обладает почти теми же правами, что и `OWNER`, в рамках своего тенанта. Ключевые отличия:

1. **Финансы** доступны только если включены **оба** флага: платформенный `finance.turnoverReport !== false`
   **и** пер-org `accessControl.financeReportForAdmin === true`.
2. На **дашборде** нет блока «Связь с поддержкой» и входящих сообщений (это только для OWNER).
3. **Перевыставление коммуналки** субарендаторам требует тех же финансовых прав (`financeOwnerOrAdmin`).
4. ADMIN **может** подать запрос на удаление своего аккаунта в «Профиль и приватность» (в отличие от OWNER).

Для всех общих форм тест-кейсы совпадают с `role-owner.md` — выполнять под учётной записью `ADMIN`.
Ниже только специфика ADMIN.

## Совпадающие формы (выполнять OWNER-кейсы под ADMIN)

| Форма | Кейсы из role-owner.md |

## Специфика ADMIN

### Дашборд тенанта

#### TC-ADMIN-DASH-01 — [Отображение] KPI и быстрые действия
- **Ожидаемый результат:** KPI-карточки и кнопки быстрых действий присутствуют (как у OWNER, `TC-OWNER-DASH-01/02`).

#### TC-ADMIN-DASH-02 — [Доступ] Нет блока поддержки/входящих
- **Ожидаемый результат:** раздел «Связь с поддержкой» и таблица входящих сообщений **не отображаются** (только для OWNER).

### Финансы — зависимость от фиче-флагов

#### TC-ADMIN-FIN-FLAG-01 — [Доступ] Меню «Финансы» при выключенном пер-org флаге
- **Предусловие:** `accessControl.financeReportForAdmin` не включён.
- **Ожидаемый результат:** пункт «Финансы» в меню **отсутствует** у ADMIN.

#### TC-ADMIN-FIN-FLAG-02 — [Доступ/403] Прямой URL финансов без прав
- **Шаги:** при выключенном флаге открыть `/manage/finance/turnover` по прямому URL.
- **Ожидаемый результат:** страница открывается, но `GET /finance/turnover/summary` возвращает 403; отображается Alert
  «Не удалось загрузить сводный оборот» (сообщение о правах/подписке), не падение.

#### TC-ADMIN-FIN-FLAG-03 — [Доступ] Меню «Финансы» при включённых обоих флагах
- **Предусловие:** `finance.turnoverReport !== false` **и** `accessControl.financeReportForAdmin === true`.
- **Ожидаемый результат:** пункт «Финансы» виден; все финансовые формы работают как у OWNER —
  выполнить `TC-OWNER-FIN-TURN-01..06`, `TC-OWNER-FIN-CAT-01..04`, `TC-OWNER-FIN-EXP-01..04`, `TC-OWNER-FIN-TC-01..04` под ADMIN.

#### TC-ADMIN-FIN-FLAG-04 — [Доступ/403] Перевыставление коммуналки
- **Шаги:** в Биллинге у счёта «Перевыставить» → «Распределить».
- **Ожидаемый результат:** при наличии финансовых прав (`financeOwnerOrAdmin`) — аллокации создаются (`TC-OWNER-BILL-07`);
  без прав — backend отклоняет (403), несмотря на видимую кнопку.

### Профиль и приватность

#### TC-ADMIN-PRIVACY-01 — [Кнопка] Запрос на удаление аккаунта доступен
- **Шаги:** `/go/account/privacy` → «Удалить аккаунт» → ввести свой email и причину → подтвердить.
- **Ожидаемый результат:** для ADMIN кнопка **активна** (в отличие от OWNER); `DELETE /api/account/privacy` создаёт
  `AccountDeletionRequest`, аккаунт деактивируется, выполняется logout. См. `TC-ANON-PRIVACY-04`.
