# Тест-кейсы: INSTRUCTOR (преподаватель)

Преподаватель ведёт занятия. Основные собственные действия: работа со **своими**
предметами, своё расписание, свои пропуска, регистрация входа (ресепшн доступен), личный кабинет,
обратная связь. Большинство справочников — только для чтения; мутации отклоняются бэкендом (403).

Сквозные проверки (`CONV-*`) применимы.

---

## Форма: Дашборд тенанта

### TC-INSTRUCTOR-DASH-01 — [Отображение] Дашборд
- **Ожидаемый результат:** личная главная преподавателя (ближайшее занятие, «Вести занятие · посещаемость», быстрые действия). Не админ-KPI; блока поддержки нет.

---

## Форма: Предметы (без тарифных планов)

Эндпоинты: `GET /subjects`, `GET /subjects/{id}`.

### TC-INSTRUCTOR-SUBJ-01 — [Доступ] Список предметов только для чтения
- **Ожидаемый результат:** таблица предметов видна; нет кнопок создания/редактирования/каталога/зачисления; колонка «Каталог» — тег, не Switch.

### TC-INSTRUCTOR-SUBJ-02 — [Устарело] Тарифные планы предмета
- **Статус:** удалено в V63. Не прогонять. Исторический шаг «иконка Тарифные планы» больше не актуален.

### TC-INSTRUCTOR-SUBJ-03 — [Упрощение] Тарифные планы удалены
- **Ожидаемый результат:** в разделе «Предметы» нет операций создания/удаления/согласования тарифов.

### TC-INSTRUCTOR-SUBJ-04 — [Доступ] Нет согласования/отклонения
- **Ожидаемый результат:** кнопки «Согласовать»/«Отклонить» недоступны (только OWNER/ADMIN).

---

## Форма: Пропуска (`/manage/access`)

### TC-INSTRUCTOR-ACCESS-01 — [Отображение] Только свои пропуска
- **Ожидаемый результат:** список = пропуска текущего пользователя; колонка «Владелец» скрыта; станция/оплата/возврат скрыты.

### TC-INSTRUCTOR-ACCESS-02 — [Кнопка] Регистрация входа (ресепшн доступна преподавателю)
- **Шаги:** вкладка «Регистрация входа» → поиск по коду → вход для `canCheckIn`.
- **Ожидаемый результат:** `GET /access/check-in/search`, `POST /access/check-in` отрабатывают для INSTRUCTOR; вход регистрируется.

### TC-INSTRUCTOR-ACCESS-03 — [Доступ/403] Записывающие действия / журнал
- **Ожидаемый результат:** создание шаблона/выдача/заморозка/отзыв и «Журнал доступа» — backend 403.

---

## Форма: Личный кабинет (`/manage/me/*`)

Эндпоинт: `GET /schedule/entries?from&to&instructorId=<user.id>`.

### TC-INSTRUCTOR-ME-01 — [Отображение] Главная ЛК
- **Ожидаемый результат:** карточки «Моё расписание» и «Отметиться по QR» (без «График работы»).

### TC-INSTRUCTOR-ME-02 — [Отображение] Моё расписание (фильтр по преподавателю)
- **Шаги:** открыть «Моё расписание», листать недели.
- **Ожидаемый результат:** запрос с `instructorId=user.id`; показаны только занятия, где преподаватель — текущий пользователь; данные из БД (заголовок/время/зал).

### TC-INSTRUCTOR-ME-03 — [Кнопка] Отметиться по QR
- **Ожидаемый результат:** `POST /access/gate/scan` / `POST /access/check-in`; вход регистрируется при валидном пропуске/слоте; deny-коды отображаются понятно.

### TC-INSTRUCTOR-ME-04 — [Доступ] График работы недоступен
- **Ожидаемый результат:** `/manage/me/work` → «Раздел доступен администраторам и владельцу.»

---

## Формы только для чтения / 403

### TC-INSTRUCTOR-RO-01 — [Доступ/403] Расписание и помещения/залы
- **Ожидаемый результат:** просмотр работает; создание/изменение/удаление записей, помещений и залов (в т.ч. архив/восстановление) — backend 403.

### TC-INSTRUCTOR-RO-02 — [Доступ/403] Биллинг, Экспорт
- **Ожидаемый результат:** просмотр данных; мутации/экспорт → 403.

### TC-INSTRUCTOR-RO-03 — [Доступ] Финансы скрыты
- **Ожидаемый результат:** меню «Финансы» отсутствует; прямой URL → 403.

### TC-INSTRUCTOR-RO-04 — [Доступ] Преподаватели/Ученики (только чтение)
- **Ожидаемый результат:** Alert «У вас только просмотр…»; данные из БД; действий записи нет.

### TC-INSTRUCTOR-RO-05 — [Доступ/403] Субаренда — создание брони запрещено
- **Шаги:** «Новое бронирование» → попытаться создать.
- **Ожидаемый результат:** просмотр доступности/списка работает; создание брони отклоняется бэкендом (только OWNER/ADMIN/SUB_TENANT).

### TC-INSTRUCTOR-RO-06 — [Доступ/403] Новости, Заявки
- **Ожидаемый результат:** формы видны; `POST/PUT/DELETE` отклоняются (403).

### TC-INSTRUCTOR-RO-07 — [Доступ] График админов (только чтение)
- **Ожидаемый результат:** таблица видна; кнопок добавления/удаления нет.

---

## Форма: Настройки

### TC-INSTRUCTOR-SET-01 — [Доступ/403] Вкладки и сохранение
- **Ожидаемый результат:** вкладки видны; сохранение по Организации/Публичному сайту/Владельцу → 403; «Администраторы» — только чтение.

### TC-INSTRUCTOR-SET-02 — [Кнопка] Смена своего пароля
- **Ожидаемый результат:** `POST /auth/change-password` отрабатывает; пароль изменён.

---

## Форма: Обратная связь

### TC-INSTRUCTOR-FEEDBACK-01 — [Кнопка][Сохранение] Отправка обращения
- **Ожидаемый результат:** `POST /feedback`; тикет создан; виден в «Мои обращения».

## Профиль и приватность

### TC-INSTRUCTOR-PRIVACY-01 — [Кнопка] Запрос на удаление аккаунта
- **Ожидаемый результат:** кнопка активна; сценарий `TC-ANON-PRIVACY-04`.
