# Матрица доступа «роль × форма»

> **Навигация (актуально).** Меню строится из `frontend/src/routing/navConfig.tsx`.
> Группы: **Проходная**, **Работа**, **Каталог**, **Кадры**, **Финансы**, **Студия**.
> - **Клиенты** — группа «Работа» (не «Кадры»). **Сотрудники** и **Заявки на отсутствие** — «Кадры».
> - График смен — вкладка **«График работы»** у сотрудников (`/manage/admin-work` → `staff?tab=schedule`).
> - Ресепшн OWNER/ADMIN — **«Регистрация входа»** (`/manage/gate`). У INSTRUCTOR — вкладка на «Мои пропуска».
> - Шаблоны абонементов — **Финансы → Абонементы**, не вкладка «Пропусков».
> - Подписи **«Заявки на отсутствие»** (не «Обращения»). Плюс пункты **«Отзывы»**, **«Баги и предложения»**.
> - `/manage/me` редиректит на Главную. Desktop-only: финансы, клиенты, кадры, новости, отзывы.

Легенда:
- **✓** — форма доступна в меню и используется ролью.
- **URL** — не в меню, но открывается по прямому URL (платформенные операторы в контексте тенанта).
- **RO** — доступна только для чтения (UI прячет/блокирует действия записи).
- **403** — UI показывает форму/кнопки, но запись отклоняется бэкендом.
- **—** — недоступно/неприменимо.
- **flag** — доступно только при включённых фиче-флагах (см. примечание про финансы).

## CLEANER (отдельная колонка не в таблице выше)

| Форма | CLEANER |
|-------|---------|
| Главная (личная) | ✓ |
| Проход (QR) `/me/scan` | ✓ (`/access/gate/scan`, check-in) |
| Мои пропуска | ✓ (только свои) |
| Заявки на отсутствие `/me/requests` | ✓ |
| Обратная связь, Баги и предложения | ✓ |
| Расписание, залы, финансы, кадры, настройки, новости | — (меню скрыто, URL → Главная) |

> **Важно про фронтенд vs бэкенд.** Для части форм запись по-прежнему режется `403` на API.
> Кейсы **[Доступ/403]** обязательны. Лёгкие роли: админские пункты **скрыты** в меню.
