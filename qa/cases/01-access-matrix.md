# Матрица доступа «роль × форма»

> **Обновление навигации (2026, роле-адаптивное меню).** Меню переработано: вместо единого
> плоского списка строится по роли и вьюпорту из `frontend/src/routing/navConfig.tsx`.
> Ключевые изменения, влияющие на таблицу ниже:
> - **Персональные «Главные».** Для STUDENT/INSTRUCTOR/SUB_TENANT/CLEANER дашборд рендерит
>   личную главную (ближайшее занятие/бронь, пропуск, быстрый проход по QR), а не админ-панель.
> - **Группа «Люди» переразбита** на **«Сотрудники»** (`/manage/staff`: ADMIN/CLEANER + INSTRUCTOR,
>   вкладки) и **«Клиенты»** (`/manage/clients`: STUDENT + SUB_TENANT, вкладки). Старые пути
>   `/manage/instructors` и `/manage/students` редиректят на них. Вкладка «Администраторы» убрана из
>   «Настроек».
> - **Лёгкие роли больше не видят админские пункты** (Залы, Финансы, Сотрудники/Клиенты, Новости,
>   Настройки, График сотрудников и т.п.) — они скрыты в меню, а прямой URL гардом редиректит на
>   «Главную» для финансов/экспорта/заявок/обращений. Записывающие кнопки на общих формах
>   (Пропуска, Расписание, Субаренда) теперь **скрыты** для ролей без прав (а не только отклоняются 403).
> - **«Пропуска» для лёгких ролей** показывают только вкладку «Мои пропуска» (ресепшн «Регистрация
>   входа» — преподавателю и OWNER/ADMIN; шаблоны/журнал/станция — только OWNER/ADMIN).
> - **CLEANER** получил роль в меню: «Главная», «Проход (QR)» (бэкенд теперь допускает CLEANER в
>   `/access/gate/scan` и `/access/check-in`), «Обращения», «Мои пропуска», «Обратная связь».
> - **«Личный кабинет» (`/manage/me`)** свёрнут в основную навигацию: «Моё расписание» (`me/schedule`),
>   «Проход (QR)» (`me/scan`), «Обращения» (`me/requests`) — отдельные пункты группы «Моё»; индекс
>   `/manage/me` редиректит на «Главную».
> - **Новое: «Обращения сотрудников»** (`/manage/staff-requests`, OWNER/ADMIN, с бейджом новых) и
>   личные «Обращения» сотрудника (отгул/замена/уведомление об отсутствии).
> - **Мобайл.** На телефоне — нижняя панель + drawer «Ещё»; «тяжёлые» разделы (Финансы, Экспорт,
>   Сотрудники/Клиенты, График сотрудников, Новости, Публичный сайт, Настройки) скрыты как desktop-only.

Легенда:
- **✓** — форма доступна в меню и используется ролью.
- **URL** — не в меню, но открывается по прямому URL (платформенные операторы в контексте тенанта).
- **RO** — доступна только для чтения (UI прячет/блокирует действия записи).
- **403** — UI показывает форму/кнопки, но запись отклоняется бэкендом.
- **—** — недоступно/неприменимо.
- **flag** — доступно только при включённых фиче-флагах (см. примечание про финансы).

## CLEANER (отдельная колонка не в таблице выше)

| Форма | CLEANER |
|-------|---------|
| Главная (личная) | ✓ |
| Проход (QR) `/me/scan` | ✓ (`/access/gate/scan`, check-in) |
| Мои пропуска | ✓ (только свои) |
| Обращения сотрудника `/me/requests` | ✓ |
| Обратная связь | ✓ |
| Расписание, залы, финансы, люди, настройки, новости | — (меню скрыто, URL → Главная) |

> **Важно про фронтенд vs бэкенд.** Для части форм запись по-прежнему режется `403` на API.
> Кейсы **[Доступ/403]** обязательны. Лёгкие роли: админские пункты **скрыты** в меню.
