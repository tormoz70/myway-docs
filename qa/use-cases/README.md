# Каталог use case'ов студии (отрасль → MyWay)

Независимое исследование ролей и дневного цикла танцевальных/йога-студий и площадок аренды залов. Сначала — язык отрасли, без привязки к экранам MyWay; сверка с продуктом — отдельный документ.

## Шаблон ID use case

- Префикс — **отраслевая роль**, не `Role.java`: `UC-FRONTDESK-03`, `UC-TEACHER-02`, `UC-CLIENT-05`, `UC-RENTER-01`.
- Поля: актёр, цель/триггер, шаги «в жизни студии», изменяемые данные, частота, боль без процесса.

## Маппинг отраслевых ролей → MyWay

Сводная таблица — в [myway-gap.md](./myway-gap.md#маппинг-отраслевых-ролей-на-myway). Кратко:

| Отрасль | Ближайшая роль MyWay | Комментарий |
|---------|----------------------|-------------|
| Владелец | `OWNER` | Полный контроль организации |
| Управляющий филиалом | `OWNER` или `ADMIN` | В MyWay нет отдельной роли «управляющий» |
| Администратор ресепшена | `ADMIN` | Операции + продажи; финансы — по флагу |
| Старший администратор | `ADMIN` (+ флаг финансов) | Нет иерархии админов в RBAC |
| Преподаватель | `INSTRUCTOR` | Свое расписание, посещаемость, заявки |
| Ассистент | — | Нет отдельной роли |
| Ученик (взрослый) | `STUDENT` | Клиент = STUDENT в продукте |
| Родитель | `STUDENT` (аккаунт ребёнка) | Нет роли «родитель»; часто один аккаунт на семью |
| Арендатор зала | `SUB_TENANT` | Субаренда, свои брони и счета |
| Уборщица | `CLEANER` | График, заявки на отсутствие |
| Маркетолог | — | Вне RBAC; OWNER/ADMIN вручную |
| Оператор платформы | `SUPER_ADMIN` / `SUPER_USER` | Вне студии |
