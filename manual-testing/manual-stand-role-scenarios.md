# Сценарии ручного теста по ролям (локальный стенд)

Практический прогон **всех ролей** на данных `scripts/qa/seed_manual_test_stand.py`.  
Подробные кейсы с полями форм — в [qa/cases/](../qa/cases/). Руководства: `user-guides/ru/role-*.md`.

**Пароль у всех:** `ManualQa12!`  
**Стенд:** http://127.0.0.1:5173  
**Полный список учёток:** `myway/generated/manual-test-stand.json`

Рекомендуемый порядок: аноним → платформа → OWNER (создаёт занятие) → ADMIN → INSTRUCTOR → STUDENT → SUB_TENANT → CLEANER → негативы и изоляция.

## Учётки стенда

| Роль | Email | Вход |
|------|-------|------|
| SUPER_ADMIN | `superadmin@myway.local` | http://127.0.0.1:5173/go/login |
| SUPER_USER | `su@myway.local` | http://127.0.0.1:5173/go/login |
| OWNER | `owner.ritm@myway.local` | http://127.0.0.1:5173/go/ritm-hall/login |
| ADMIN | `admin.ritm@myway.local` | то же |
| INSTRUCTOR | `instr.irina.ritm@myway.local` | то же (+ вторая студия «Флоу Стрит») |
| STUDENT | `student.ritm@myway.local` | то же |
| SUB_TENANT | `sub.ritm@myway.local` | то же |
| CLEANER | `cleaner.ritm@myway.local` | то же |

Другие студии (те же роли, префиксы `*.flow@` / `*.svet@`):

- **Флоу Стрит** — http://127.0.0.1:5173/go/flow-street/login
- **Светлая Практика** — http://127.0.0.1:5173/go/svet-praktika/login

База: «Ритм Холл» — 5 залов, 9 предметов, **~4 месяца расписания** (май–сентябрь) и финансы; своё
занятие OWNER всё равно создаёт в S-OWN-03.

После досева фикстур симулятора (`--simulator-fixtures`, см. [qa/use-cases/simulator.md](../qa/use-cases/simulator.md))
в каталоге появляются ещё три предмета — `Sim UC Waitlist`, `Sim UC Makeup`, `Sim UC Substitute` —
и занятия с такими названиями. Это данные автотестов, для ручного прогона их можно игнорировать.

## S-SA / S-SU — платформа

Вход: `/go/login` → должно открыться **`/go/platform`**.

### SUPER_ADMIN (`superadmin@myway.local`)

| ID | Шаги | Ожидание |
|----|------|----------|
| S-SA-01 | Вкладки: Тенанты, Профиль, **Операторы**, Тарифы, Подписки, Заявки, Обращения | Все вкладки есть. В тенантах видны `ritm-hall`, `flow-street`, `svet-praktika` (и `divan`, если была) |
| S-SA-02 | Тенанты: фильтр по slug `ritm-hall` | Одна строка, владелец `owner.ritm@myway.local`, есть пользователи |
| S-SA-03 | Операторы | В списке `su@myway.local`. Форма «Добавить SUPER_USER» видна |
| S-SA-04 | Открыть `/go/ritm-hall/manage/finance/turnover` | Нет сводного оборота тенанта (платформа не видит финансы студии) — редирект/пустое меню студии |

| ID | Шаги | Ожидание |
|----|------|----------|
| S-SU-01 | `/go/platform` | Тенанты, тарифы, подписки, заявки, обращения **есть** |

| ID | Шаги | Ожидание |

## S-SUB — SUB_TENANT

`sub.ritm@myway.local`

**Меню:** Главная; Проходная → **Субаренда**, Мои пропуска; Предметы; Баги; Обратная связь. **Нет** «Проход (QR)» как у студента? По коду `me-scan` доступен **всем** ролям тенанта, включая SUB_TENANT — пункт «Проход (QR)» **есть**. Станционный QR для субарендатора в гайде не предусмотрен как рабочий контур — проверить, что сканер открывается, но админской «Регистрации входа» нет.

| ID | Шаги | Ожидание |
|----|------|----------|
| S-SUB-01 | Главная | Ближайшее бронирование / «Забронировать зал» |
| S-SUB-02 | Субаренда → бронь «Зал 5 — Большая сцена» на завтра 2 часа | Слот свой, виден в сетке доступности |
| S-SUB-03 | Кнопки «подтвердить бронь» / «выставить счёт» | **Скрыты** (это OWNER/ADMIN) |
| S-SUB-04 | `/manage/rooms`, `/manage/clients` | Редирект на Главную |
| S-SUB-05 | Под OWNER открыть Субаренду | Видно бронь Дениса; можно подтвердить и выставить счёт |

| ID | Шаги | Ожидание |
|----|------|----------|
| S-ISO-01 | OWNER «Ритм Холл» открывает `/go/flow-street/manage/dashboard` | Нет чужого кабинета (логин/403/своя орг) |

## Чеклист прогона (короткий)

Отмечать по ходу:

- [ ] Аноним: три визитки + join-формы
- [ ] SUPER_ADMIN: тенанты + Операторы
- [ ] SUPER_USER: без Операторов
- [ ] OWNER: каталог 5 залов / 9 предметов, занятие, пропуск, финансы, новость
- [ ] ADMIN: операции да, финансы нет
- [ ] INSTRUCTOR: посещаемость, нет удаления, нет залов; вторая студия тем же email
- [ ] STUDENT: своё расписание и пропуск
- [ ] SUB_TENANT: бронь зала, счёт только у OWNER
- [ ] CLEANER: QR + обращение, без каталога
- [ ] Прямые URL чужих разделов → Главная
- [ ] Тенанты не видят данные друг друга

Повторный seed (идемпотентно):

```powershell
python scripts/qa/seed_manual_test_stand.py
```
