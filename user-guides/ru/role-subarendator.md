# Руководство субарендатора

Вы — **SUB_TENANT**. Бронируете залы своей студии на `/go/<slug>`. Кабинета владельца, финансов и кадров у вас нет.

Другие роли: [оглавление](./README.md).

<a id="vhod"></a>

## Вход

Кнопка **«Войти»** на витрине → `/go/<slug>/login`. Заявку на аренду с сайта обрабатывают в **Клиенты**.

![Страница входа](../assets/login-page.png)

<a id="kabinet-i-menyu"></a>

## Меню

| Группа | Пункты |
|--------|--------|
| | **Главная** |
| **Проходная** | Субаренда, Проход (QR), Мои пропуска |
| **Каталог** | Предметы (просмотр) |
| | Баги и предложения, Обратная связь |

**Главная:** ближайшее бронирование, **«Забронировать зал»**.

<a id="subarenda"></a>

## Субаренда

Ваши брони: создание, правка, отмена. Подтверждение, счёт и оплата — у владельца/администратора (эти кнопки скрыты).

![Доступность и бронирования](../assets/sublease-workspace.png)

Статусы: Черновик, Подтверждено, Отменено, Завершено. Вкладка счетов — ваши счета, без приёма оплаты за студию.

<a id="propuska"></a>
<a id="prohodnaya"></a>

## Проход и пропуска

**Проход (QR)** — отметить вход камерой или токеном. **Мои пропуска** — только свои. Станции ресепшн `/manage/gate` нет.

<a id="predmety"></a>

## Предметы

Только просмотр каталога.

<a id="obratnaya-svyaz"></a>

## Обратная связь

Чат с владельцем студии. **Профиль и приватность** — экспорт и удаление аккаунта.
