# Руководство клинера

Вы — **CLEANER**. Нужны только сайт студии `/go/<slug>` и проход. Расписания, залов, финансов и кадров в меню нет.

Другие роли: [оглавление](./README.md).

<a id="vhod"></a>

## Первый вход

Приглашение: администрация → **Сотрудники → Клинер**. Письмо с **временным паролем** → `/go/<slug>/login` → **«Смена пароля»**. Смена email снова шлёт пароль.

![Страница входа](../assets/login-page.png)

## Меню

| Группа | Пункты |
|--------|--------|
| | **Главная** |
| **Проходная** | Проход (QR), Мои пропуска, Заявки на отсутствие |
| | Баги и предложения, Обратная связь |

**Главная:** **«Отметиться по QR»**, переход к заявкам на отсутствие, карточка пропуска (если выдан).

<a id="prohodnaya"></a>
<a id="propuska"></a>

## Проход и пропуск

**Проход (QR):** станционный код камерой или токен личного пропуска. Режим «только по графику» настраивает администрация (шаблон абонемента + график работы сотрудников).

**Мои пропуска** — только ваш абонемент, без шаблонов и журнала.

<a id="kadry"></a>

## Заявки на отсутствие

Отгул, замена, «не смогу прийти». Статус виден у вас; меняет его администрация в **Кадры → Заявки на отсутствие**.

<a id="obratnaya-svyaz"></a>

## Обратная связь

Чат с владельцем. Баги — **«Баги и предложения»**. Удаление аккаунта в приватности доступно.
